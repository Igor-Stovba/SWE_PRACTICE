# Ошибки и их решения

## Проблемы 
1) Нет разделения на приватные и публичные методы и атрибуты
2) Методы описаны только для одного класса (Диспетчер)
3) Нет разделения на интерфейсы и реализации
4) Нет ассоциаций между классами (агрегация/композиция)
5) Не прописаны связи между классами
6) Не выделены классы: Бригадир, Начальник цеха, Бухгалтер

## Пути решения проблем
1) Выделить публичный и закрытый  API у классов. Это создаст определенные контракты между сущностями и упростит тестирование
2) Описать сигнатуры методов в классах, чтобы были видны функциональные возможности. 
3) Сделать интерфейсы, например, для отчетов, т.к. мы не можем обеспечить требуемую функциональность одним классом. 
4) Добавить явные виды отношений (1:1, N:1, N:M)
5) Добавить композицию и агрегацию в диаграмму.
6) Декомпозировать задачу в соответствии с требованиями к системе.
